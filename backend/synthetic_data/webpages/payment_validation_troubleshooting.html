Troubleshooting Payment Request Validation Errors

Published 2026-05-03. General guide. Not about any specific company.

What a validation error means

A validation error means the server read your request but the body did not match the schema it expects. The server never tried to charge the payment. Retrying the same body will fail the same way.

Common causes

The most common causes are: a renamed field that one client still sends with the old name, a missing required field, a wrong type (for example the amount sent as a string), and a library upgrade on the server that changed how the schema is applied.

How to check

Put one failing request next to one working request and compare the field names. If only one client or one code path fails, the problem is usually that client's request shape, not the network or the database. Check the server's dependency changelog when errors begin right after a deploy.

A note on retries

Validation errors are not temporary. Clients that retry them only add load and delay. Many teams retry only on 5xx responses and timeouts.
